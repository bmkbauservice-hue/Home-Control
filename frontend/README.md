# Home Control – Frontend

React-Oberfläche von Home Control (React, TypeScript, Vite).

Installation, Start und die gesamte Projektdokumentation stehen in der
[README im Projektordner](../README.md) und unter [docs/](../docs/).

Kurzfassung (in diesem Ordner):

```bash
npm install     # Pakete installieren
npm run dev     # Entwicklungsserver auf http://localhost:5173 (Backend muss auf Port 5111 laufen)
npm run build   # TypeScript prüfen und Produktions-Build nach dist/
npm run lint    # Linter oxlint
```
